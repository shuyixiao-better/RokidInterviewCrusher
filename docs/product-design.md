# 产品设计文档

## 1. 产品概述

### 1.1 产品名称
**吊打面试官** (RokidInterviewCrusher)

### 1.2 产品定位
基于 Rokid 智能眼镜的 AI 面试训练与复盘辅助工具

### 1.3 目标用户
- 准备技术面试的程序员
- 需要提升面试表现的求职者
- 希望系统化练习面试的用户

### 1.4 核心价值
- **实时辅助**：面试过程中提供关键词提示
- **智能分析**：AI 自动分析面试表现
- **便携体验**：基于智能眼镜，无需额外设备
- **隐私保护**：所有功能需用户主动触发

## 2. 用户场景

### 2.1 场景一：模拟面试训练
**用户故事**：作为一个准备面试的程序员，我希望在模拟面试时获得实时提示，以便更好地组织回答。

**流程**：
1. 用户打开应用，点击"开始面试"
2. 系统开始录音并监听语音
3. 当检测到面试问题时，AI 生成关键词提示
4. 眼镜上显示提示，用户参考提示组织回答
5. 面试结束后，系统生成复盘报告

### 2.2 场景二：面试复盘分析
**用户故事**：作为一个刚完成面试的求职者，我希望获得详细的复盘分析，以便了解自己的不足并改进。

**流程**：
1. 用户完成一次面试
2. 系统自动转写面试录音
3. AI 分析面试内容并生成报告
4. 用户查看评分、问题分析和改进建议
5. 根据建议进行针对性练习

### 2.3 场景三：个性化配置
**用户故事**：作为一个有特定技术栈的开发者，我希望配置我的技术背景，以便获得更精准的提示。

**流程**：
1. 用户进入设置页面
2. 配置目标岗位、技术栈、简历关键词
3. 配置 AI API 接口
4. 保存配置并开始使用

## 3. 功能设计

### 3.1 首页

#### 功能
- 显示应用名称和副标题
- 提供"开始面试"入口
- 提供"查看复盘"入口
- 提供"设置"入口
- 显示最近面试记录摘要

#### 交互
- 点击按钮进入对应页面
- 显示最近一次面试的基本信息

### 3.2 面试页面

#### 功能
- 开始/停止面试
- 实时显示录音状态
- 显示当前识别的问题
- 显示关键词提示
- 显示录音时长

#### 交互
- 点击"开始面试"启动录音和识别
- 点击"结束面试"停止并生成复盘
- 实时更新状态和提示

#### 状态
- 准备开始
- 录音中
- 分析中
- 等待问题
- 已完成

### 3.3 复盘页面

#### 功能
- 显示面试基本信息
- 显示综合评分
- 显示各维度评分
- 显示问题列表和分析
- 显示主要问题
- 显示下一步计划

#### 交互
- 点击问题卡片展开详情
- 点击"开始新面试"进入面试页面
- 点击返回回到首页

### 3.4 设置页面

#### 功能
- 配置目标岗位
- 配置技术栈
- 配置简历关键词
- 配置 AI API
- 清空数据

#### 交互
- 选择/取消选择岗位
- 添加/移除技术栈
- 添加/移除关键词
- 测试 API 连接
- 确认清空数据

## 5. 交互设计

### 5.1 眼镜端交互原则

#### 屏幕限制
- 屏幕尺寸小，信息密度低
- 需要快速浏览，减少滚动
- 字体清晰，对比度高

#### 操作方式
- 简单点击操作
- 减少输入操作
- 明确的视觉反馈

#### 信息展示
- 关键信息优先
- 分层次展示
- 使用图标辅助

### 5.2 关键交互流程

#### 开始面试流程
```
用户点击"开始面试"
    ↓
显示合规提示
    ↓
用户确认授权
    ↓
开始录音
    ↓
显示录音状态
    ↓
监听语音识别
    ↓
检测到问题
    ↓
调用 AI 生成提示
    ↓
显示关键词提示
```

#### 结束面试流程
```
用户点击"结束面试"
    ↓
停止录音
    ↓
停止语音识别
    ↓
显示"分析中"
    ↓
转写完整录音
    ↓
调用 AI 生成复盘
    ↓
保存面试记录
    ↓
跳转到复盘页面
```

## 6. 视觉设计

### 6.1 色彩方案

#### 主色调
- 主色：#1890FF（蓝色）
- 成功：#52C41A（绿色）
- 警告：#FAAD14（黄色）
- 错误：#FF4D4F（红色）

#### 背景色
- 主背景：#F5F5F5
- 卡片背景：#FFFFFF
- 深色背景：#001529

### 6.2 字体规范

#### 标题
- 大标题：24px，加粗
- 小标题：18px，加粗
- 区域标题：16px，加粗

#### 正文
- 正文：14px
- 辅助文字：12px
- 最小文字：10px

### 6.3 组件规范

#### 按钮
- 主按钮：蓝色背景，白色文字
- 次按钮：白色背景，蓝色边框
- 危险按钮：红色背景，白色文字

#### 卡片
- 圆角：8px
- 阴影：0 2px 8px rgba(0,0,0,0.1)
- 内边距：16px

#### 标签
- 技术栈标签：小圆角，彩色背景
- 状态标签：圆角，对应颜色

## 8. 非功能性需求

### 8.1 性能需求
- 页面加载时间 < 2 秒
- AI 响应时间 < 5 秒
- 语音识别延迟 < 1 秒

### 8.2 可用性需求
- 支持离线使用（Mock 模式）
- 支持多种浏览器
- 支持 Rokid 智能眼镜

### 8.3 安全性需求
- 用户数据本地存储
- API Key 加密存储
- 不收集用户隐私数据

### 8.4 可维护性需求
- 代码模块化
- 组件可复用
- 配置可扩展

## 9. 合规要求

### 9.1 用户授权
- 所有录音功能必须由用户主动触发
- 明确提示用户获得相关方授权
- 不提供隐藏录音功能

### 9.2 功能限制
- 实时提示只提供关键词，不生成完整答案
- 不鼓励在未授权的正式面试中使用
- 不提供绕过系统检测的功能

### 9.3 数据安全
- 录音数据本地存储
- 不自动上传到云端
- 用户可随时清空数据

### 9.4 使用场景
- ✅ 模拟面试训练
- ✅ 面试复盘分析
- ✅ 表达能力提升
- ❌ 正式面试作弊
- ❌ 隐蔽录音录像
